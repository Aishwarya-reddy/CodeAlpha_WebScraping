# CodeAlpha Web Scraping Project

## Project Description
This project is developed as part of the CodeAlpha Data Analytics Internship.

The project uses Python libraries such as:
- Requests
- BeautifulSoup
- Pandas

to scrape book data from the website:
https://books.toscrape.com/

## Extracted Data
- Book Name
- Price
- Rating

## Output
The scraped data is stored in a CSV file named:
books_data.csv

## Technologies Used
- Python
- BeautifulSoup
- Pandas
